# Excel VLSM · entregable A

`VLSM_Hospital_G3.xlsx` calcula las 9 redes **con fórmulas** (no hay tablas pegadas). Si cambias los hosts de una red, todo se recalcula.

| Hoja | Contenido |
|---|---|
| **VLSM** | Las 9 redes de mayor a menor: bits de host, 2ⁿ, 2ⁿ−2, prefijo, máscara binaria y decimal, red, primer y último host, broadcast, gateway, VLAN, asignación física, alineación y capacidad |
| **Parametros** | El bloque elegido (172.16.0.0/22) y su número entero |
| **Reservas** | Tabla de direccionamiento final: cada equipo con IP, máscara, gateway, DNS y puerto |
| **Como estudiar** | Notas para practicar |

Las celdas en **azul** son datos de entrada; el resto son fórmulas.

👉 Explicación de cada columna y de cada fórmula: [docs/02_vlsm_y_excel_paso_a_paso.md](../docs/02_vlsm_y_excel_paso_a_paso.md)
